# Исходники 3D-персонажа героя (CC0)

- `ubc/` — Quaternius, «Universal Base Characters» (Standard), CC0: мужская модель, стрижка, борода, брови.
- `ual/` — Quaternius, «Universal Animation Library» (Standard), CC0: анимации на тот же скелет.

Запекание в листы игры: `python3 tools/glbchar/bake_hero.py` (пути по умолчанию — эта папка).
Лишнее из архивов (женская модель, FBX, другие причёски) удалено, чтобы не раздувать репозиторий.
